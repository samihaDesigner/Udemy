# Udemy
# Project Overview
This project is a simplified clone of Udemy, a popular online learning platform, created using HTML, CSS, and CSS animations. It aims to replicate the core functionalities and aesthetics of the original website, focusing on the user interface and experience.

# Technologies Used
HTML: The foundation for structuring the content of the website.
CSS: Used to style and design the layout, colors, fonts, and overall appearance.
CSS Animations: Employed to create dynamic and engaging visual effects.
# Project Structure
├── index.html
├── styles.css
└── animations.css
# index.html
Contains the HTML structure of the website, including the header, main content area, and footer.
# styles.css
Houses the general CSS styles for the project, such as typography, colors, and layout.
# animations.css
Defines the CSS animations used throughout the website, including transitions, keyframes, and timing functions.
# Features
Responsive Design: The website is designed to adapt to different screen sizes and devices.
Navigation Menu: A navigation bar with links to different sections of the website.
Course Listings: A list of courses with titles, descriptions, instructors, and enrollment information.
Course Details: Detailed information about individual courses, including course outlines, reviews, and enrollment options.
Search Functionality: A search bar to allow users to find specific courses.
User Accounts: A simplified user account system for login and registration.
